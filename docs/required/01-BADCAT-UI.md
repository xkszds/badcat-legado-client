# 第一类必读清单：Badcat 原版 UI、页面结构与交互

> 开始第一类任务：读总流程 [00-MASTER-WORKFLOW.md](00-MASTER-WORKFLOW.md) + 本文件。通常不读其他四类；跨类时才追加受影响清单。UI map 和旧项目清单为证据/历史资料。

## 目标与边界

以 Badcat 1.5.0.5 原版 APK、用户截图、真实交互和方法级证据为准，恢复原版页面、图标/颜色、控件位置、菜单、导航和返回栈。可用现代 Kotlin/Android 实现，但不得擅自重设计。原 APK/DEX 只读；新客户端独立包身份，不覆盖原应用数据。Legado 只提供数据，不取代 Badcat UI。

## 必须保持的用户要求

- 首页、主导航、搜索入口、搜索结果、类型/来源切换、历史、详情、目录入口按原版结构和状态还原。
- 收藏夹中小说/作品入口按用户指定位置布局；不保留顶部书贴入口。
- 去掉右上角独立文件夹快捷选项；长按书籍出现移动操作，再选择文件夹。
- 三点菜单按用户提供截图实现；小说文件夹开关等选项放三点菜单，默认书籍展示不被改变。
- 收藏夹类别按用户确认使用“小说”；不恢复书贴分类。
- 我的页面移除“猫咪福利社”；“书贴管理”改为“书签管理”，阅读书签集中显示。
- 已移除的喵星、排行榜、今日抽奖等入口不得自行恢复；以用户最后确认的导航结构为准。
- 后续新截图/明确要求优先于旧描述，必须更新本清单并加验收点。

## 范围

首页/底部导航；搜索首页/结果/来源 tab/类型/分页；书籍与漫画详情；目录入口；收藏夹/文件夹/筛选/排序/长按移动/三点菜单；我的/设置/历史/书签管理；图标、颜色、字体、间距、弹窗、加载/空/错误状态。

## 当前实现记录（非最终验收）

- MainActivity/MainBottomNavigation 有搜索、收藏夹、我的等导航调整。
- 搜索页有小说/漫画/综合选择、来源 tabs、结果、分页、加载/空/错误状态。
- 收藏夹有文件夹、卡片网格、筛选/排序和管理入口基础。
- 个人中心有历史、书签管理、书源目录和替换规则入口。
- 这些记录不代表截图 parity、真实类型筛选或全部交互已完成。

## 未完成验收

- 长按移动、三点菜单、文件夹状态与用户截图一致。
- 搜索类型/来源筛选、并发取消、分页边界和返回栈正确。

1. 固定原版页面/控件/状态/操作矩阵和截图哈希。
2. 主壳、导航、首页、搜索首页。
3. 搜索结果、类型/来源、详情、目录入口。
4. 收藏夹、文件夹、长按移动、三点菜单。
5. 我的、设置、工具入口。
6. 截图回归 + Espresso + 人工真机验收。
