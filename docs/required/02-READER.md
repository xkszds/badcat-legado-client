## 目标和边界

保持坏坏猫原版在线小说、漫画、本地阅读体验、页面布局和操作流程。Legado 提供书源/章节/正文能力，但不能用 Legado Reader UI 替代 Badcat 阅读器。

必须区分四种规则：Badcat 阅读 CSS（本类）、Legado 书源 CSS/JSoup（第三类）、Legado 正文替换（第三类）、Badcat AdBlock/AdMark（第四类）。不可互相冒充或混用私有格式。

## 范围

- 小说/漫画/本地阅读入口和各自渲染流程。
- 阅读页顶部/底部工具栏、目录抽屉、章节切换、进度条、点击区域、翻页/滚动模式。
- 字体、字号、字重、行距、段距、页边距、背景、夜间/护眼、亮度、方向和设置持久化。
- 上一章/下一章、目录跳转、书签、历史、进度恢复、自动翻页/滚动、原版实际支持的听书。
- 章节缓存、离线阅读、网络失败恢复、章节切换和阅读记录生命周期。
- 阅读 CSS 方案/子选择器：新增、编辑、删除、启停、复制、排序、备注、预览、冲突、导入导出和安全限制。

## CSS 专项验收

- 还原原版样式方案和子选择器 UI、交互与数据格式。
- CSS 必须作用于原版真实 DOM/渲染结构；当前仅作用于归一化 .reader-paragraph 等节点的实现不能宣称原版任意 DOM 兼容。
- 方案和子选择器 CRUD、启停、复制、排序、备注、预览、冲突提示必须真实生效并持久化。
- 主题/字号/行距/背景联动，章节切换后持续应用。
- 原版 JSON round-trip、未知字段、异常文件和版本迁移。
- 恶意/高开销 CSS 隔离，不能污染其他页面/书籍。

## 已有实现记录（不等于原版验收）

- 有开发版阅读、历史、书签、进度保存/恢复、目录和章节导航基础。
- 有阅读设置和 WebView 章节渲染基础。
- 有 CSS 多方案、子选择器、启停、复制、排序、预览、冲突提示和 JSON 导入导出基础。
- 当前 CSS 使用客户端私有 JSON，仅证明适用于归一化章节 DOM；原版格式/DOM/UI/行为尚未证明。
- 缓存、进度恢复和后台回调有局部修正，长章节、滚动位置、重启、离线和异常恢复仍需真机验证。

## 未完成

原版阅读器逐屏/手势验收；CSS 原版格式和 DOM 作用域；全部偏好持久化；目录/进度/翻页/自动阅读真机操作；离线缓存版本失效/空间管理；阅读历史/书签/进度与第三类的唯一事实源协同；截图、Espresso、人工真机验收。

## 实施顺序

固定原版截图和手势基线 → 明确小说/漫画/本地内容契约 → 还原阅读页/目录/进度/章节导航 → 设置持久化 → CSS 数据格式/DOM 闭环 → 经 Repository/Facade 接入 Legado → 缓存/离线/历史/书签恢复 → UI 和设备验收。

每次任务先登记阅读场景、DOM/内容模型、状态所有者、Legado 边界、样本、截图和真机要求；结束回填代码、测试、CI、设备结果和差距。
